# AQZARA.AI

Open `index.html` in a modern browser. Replace the six placeholder image paths in `images/` with your project previews and founder portrait.

To activate enquiry delivery, create an EmailJS service and template, then replace `publicKey`, `serviceId`, and `templateId` in `script.js`. The template should accept `name`, `email`, `company`, `project_type`, `budget`, `message`, and `to_email`.
